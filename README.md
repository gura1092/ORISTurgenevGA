# Домашние задания по ОРИС

Репозиторий содержит домашние задания по курсу ОРИС. Каждая работа находится в отдельной папке.

## Список работ

- **HomeWork_1** — HTML и CSS: веб-страницы и поиск.
- **HomeWork_2** — HTTP-сервер на `HttpListener`.
- **HomeWork_3** — раздача статических файлов и MIME-типы.
- **HomeWork_4** — обработка HTTP-запросов и обработчики.
- **HomeWork_5** — контроллеры и отправка электронной почты.
- **HomeWork_6** — развитие собственного веб-фреймворка.
- **HomeWork_7** — HTML-шаблонизатор.
- **HomeWork_8** — модульное тестирование.
- **HomeWork_9** — собственная ORM и PostgreSQL.
- **HomeWork_10** — управление состоянием веб-приложения и HTTP Cookie.

## Примечания

- Временные файлы сборки (`bin`, `obj`), настройки IDE и результаты тестирования не включаются в репозиторий.
- Для HomeWork_9 и HomeWork_10 база данных запускается через Docker Compose из соответствующей папки проекта.
